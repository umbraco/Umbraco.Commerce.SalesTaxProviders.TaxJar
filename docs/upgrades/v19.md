# Upgrade to Umbraco 19

From Umbraco Commerce `[18.0.0, 18.999.999)` (CMS 18) to Umbraco Commerce `19.0.0-beta.1` (CMS `19.0.0-beta1`, tag `release-19.0.0-beta1`).
Branch `v19/topic/cms-19-upgrade` → PR into `release/19.0.0`, cut from `main` (`ee71245`).

**Targets CMS release:** `release-19.0.0-beta1`, via Umbraco Commerce `19.0.0-beta.1` (MyGet `umbracoprereleases`, already in `NuGet.config`). The package's own version is `19.0.0-beta.1`.

The package depends on `Umbraco.Commerce.Core`, `Microsoft.Extensions.Http` and `TaxJar`, never on `Umbraco.Cms.*` directly, so CMS breaking changes reach it only through Commerce. Commerce's own v19 inventory (Core repo, `docs/upgrades/v19.md`) is the source for those. Same pattern as the Stripe provider's v19 upgrade.

## Third-party dependencies

## Tasks

Each task ends in a green build.

- [ ] 1. Bump to .NET 11, the pinned SDK, Umbraco.Commerce.Core 19.0.0-beta.1 and Microsoft.Extensions.Http 11.0.0-rc.3.26522.148.
- [ ] 2. Unit test project for the logic that runs without TaxJar credentials: when the provider skips the call (non-US address, missing zip, non-USD), the `Tax` request it builds (addresses, amount, shipping, line items with tax code, unit price and discount), and the mapping of TaxJar's response to `SalesTaxCalculationResult` (amount to collect, jurisdictions, breakdown).
- [ ] 3. TaxJar 4 → 5 (RestSharp 108 → 114): bump, then run the task 2 tests plus a test that drives `TaxjarApi.TaxForOrderAsync` against a stub HTTP handler, if the SDK lets one be injected.
- [ ] 4. Tests in CI: run the unit test project in the pipeline (`run_tests` is `skip` with "No test projects").
- [ ] 5. Compatibility markers: version `19.0.0-beta.1`; package validation baseline comment `19.0.0`.

## Decisions

- TaxJar 5 taken in this upgrade (maintainer policy, brief for providers 02-11-2026): take majors during a major upgrade when safe, add tests where we can.
- Add tests wherever they can run without TaxJar credentials (maintainer, 30-10-2026, Stripe upgrade).

## Breaking changes for consumers

- Requires Umbraco Commerce 19 (.NET 11).
- TaxJar 5.0 (was 4.0), bringing RestSharp 114 (was 108): sites that reference TaxJar or RestSharp themselves move with it.
